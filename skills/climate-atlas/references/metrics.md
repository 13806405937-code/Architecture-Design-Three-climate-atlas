# 指标口径 · 一个数字只能有一个定义

图上每个数字都要能回答「分子分母是什么」。以下是本技能全部口径，改代码前先读这里。

---

## 1. 可照时数（denominator）

> **太阳在地平线上 = 太阳方向向量的 Z 分量 > `sunup_zmin`**，默认 `0.04`（≈ 高度角 2.29°）。

为什么不用 `alt > 0`：高度角 0–2.3° 时太阳处于地平线雾霾/建筑遮蔽带内，能量可忽略却会虚增分母，
导致日照率被系统性低估。阈值统一由 `atlas.json` 的 `sunup_zmin` 控制，`sunlit()` 与 `sun_up()` 共用同一个值。

上海 CSWD 583620 实测（8760 h）：

| 阈值 | 小时数 |
|---|---|
| alt > 0° | 4,432（native 4,388） |
| **alt > 2.29°（本文口径）** | **4,221（native 4,205）** |

## 2. 日照率

```
日照率 = 受照时数 ÷ 该时段可照时数          （0–100%）
```

**三张场地日照图（全年/夏/冬）必须用同一个定义**，否则不能横向比较。
分子是「该点在多少个小时里没被建筑遮挡」，分母是上表的口径。

上海示例（本项目场地）：全年最低 0%、中位 83%、最高 100%；夏季可照 1,196 h、冬季 893 h。

## 3. 静风与风向频率

- 静风阈值：`WS < 0.5 m/s`。静风样本**不进方位扇形**，只计入中心数字。
- 方位分箱：`floor((wd + 11.25) mod 360 / 22.5) mod 16`，即每 22.5° 一箱，箱中心对准 16 方位。
- 风向是「**风来向**」（EPW 惯例）。
- 频率分母 = 该时段**全部小时**（含静风），所以「扇形总和 = 100% − 静风率」。

上海示例：年均风速 3.25 m/s，主导 NE，静风 3.6% = 312 h（与 Ladybug 参考图 `Calm: 3.56% = 312 hours` 逐位一致，可作对照校验）。

## 4. 云量

EPW 总云量是**十分制（0–10）**，Ladybug 转成 okta（0–9 或 0–10 视版本）。
本技能统一：
- `阴天` = 云量 ≥ 8（八分量级）
- `云量过半` = 云量 ≥ 5
- `cloud_mean_pct` = 均值 ÷ 10 × 100，**是百分比**；ladybug 原始均值是 okta，两者不可直接比。
- 判断阴晴**优先用散射比 `DHI / GHI`**，比云量稳（云量列在部分数据集里缺失或全 0）。

## 5. 辐射

- `ghi_total` / `dni_total` / `dhi_total`：**月累计 Wh/m²**（不是月均功率）。
- `gha_total_kwh_m2`：全年水平面总辐射 kWh/m²·a。
- 「直射可用小时」= `DNI > 120 W/m²` 的小时数（注意与「可照时数」是两回事）。

## 6. 舒适与度日

| 指标 | 定义 |
|---|---|
| 舒适小时 | 18 ≤ TA ≤ 26 °C 且 30% ≤ RH ≤ 70% |
| 自然通风可用 | 12 ≤ TA ≤ 26 °C 且 TDEW ≤ 20 °C |
| HDD18 | Σ max(18 − TA, 0) ÷ 24（°C·d） |
| CDD26 | Σ max(TA − 26, 0) ÷ 24（°C·d） |

度日是**积分量**，不能当小时数用；HDD/CDD 的比值才是"冬夏权重"的判据。

## 7. 高度场与遮挡

- 高度场栅格 `cell` 默认 1 m，取每格最高 Z；**垂直面不贡献高度**。
- 射线采样步长 2 m，最远 320 m，超出 `zmax`（默认 30 m）后不再采样。
- 因此本引擎只回答「**某个地面点/某一标高点**是否被挡」，**不能**回答「某层某个窗是否被挡」。

## 8. 太阳位置

- native 引擎：NOAA 简化算法。**方位角必须 `atan2(e, n)`**。
- 与 ladybug 实测：高度角 |Δ| max 0.91° / mean 0.18°；方位角 |Δ| max 1.10° / mean 0.24°。
- EPW 的 `hour` 是 1–24（时段末），本技能统一转成 **0–23** 后按整点取太阳位置（与 ladybug `datetime.hour` 同口径）。
  用「小时中点」会让整体偏 1 小时，正午高度角差 5–13°。

## 9. 单位与符号

- 长度米、温度 °C、风速 m/s、辐射 Wh/m² 或 kWh/m²（差 1000）、度日 °C·d。
- 方位角自北顺时针；模型 XY 右手系。
- 所有百分比 0–100，不做 0–1 归一。
