# 模型朝向反解：四条证据法

导入的模型（Rhino / SketchUp / FBX / OBJ）几乎不会自带真北。
朝向**错 90°，所有风玫瑰、阴影、日照图全对不上，而图上完全看不出来**——这是本技能最容易翻车的一步。

原则：**不猜，用外部证据交叉验证**。四条证据中至少拿到两条同向，才写进 `atlas.json`。

---

## 口径（全包唯一表述）

```
真北 = (−sin φ, cos φ)          φ = brg_y
模型 +Y 轴方位角 = brg_y
模型 +X 轴方位角 = brg_y + 90
方位角：自北顺时针，0–360
模型 XY：右手系，X 向右、Y 向上
```

四种写法任选其一（`atlas_config.py` 会归一到上面这一组）：

```json
"orientation": { "world_axes": true }            // +Y 就是正北
"orientation": { "brg_y": 24.5 }                 // 推荐：直接给 +Y 的方位角
"orientation": { "brg_x": 114.5 }                // 给 +X 的方位角
"orientation": { "true_north_in_model": [-0.414, 0.910] }
```

自检：`python scripts/atlas_config.py` 会打印归一化后的 `brg_x / brg_y / 真北向量`。
`brg_x = 90, brg_y = 0` 表示「模型 +X = 正东」，真北向量应为 `(0, 1)`。

---

## 证据 1 · 与真实地理轮廓比对（最硬）

从 OSM / 天地图 / 高德取场地所在**建筑轮廓多边形**，量它的长轴方位角，再与模型里对应体块长轴比。

做法：
1. 取轮廓的凸包或最小外接矩形，算主方向（PCA 或最小面积矩形）。
2. 得到真实方位角 `A_real`。
3. 量模型里同一体块的主方向角 `A_model`（模型坐标系内，`atan2(dy, dx)` 得到的是与 +X 的夹角）。
4. `brg_x = (A_real − A_model + 360) % 360`。

⚠️ 长轴方位角是**双向**的（长轴既可以是 114.5° 也可以是 294.5°），单靠长轴定不出 180°，必须配合证据 3/4。

## 证据 2 · 模型自身尺寸与实测尺寸比对

用模型包围盒的长宽（米）去对实测长宽。数值能对上说明单位与缩放没问题——
**单位错（毫米当米）会让所有高度、遮挡、阴影全部失真，且图看着"似乎正常"**。
先确认 `mesh.units` 是米，再谈朝向。

## 证据 3 · 周边路网/街区走向

街区路网在多数中国城市是正交网格，方位角常落在两个峰上（例如 112.5° / 22.5°）。
把模型里明显平行于街道的体块边与路网峰对齐，能拿到粗朝向（±5°），并**排除掉 180° 的一半**。

## 证据 4 · 不对称要素定向（破 180° 歧义的关键）

找模型里**南北不对称**的特征：北侧坡道、东西向悬挑、单侧雨棚、退台方向……
把它们与卫星图上同一位置的特征比对，就能确定是哪一头朝北。

> 本项目实测：长轴 114.5° / 短轴 24.5° 两个候选（差 180°），最终靠「北侧坡道辅体 + 东西悬挑」这两处不对称要素定下 `brg_y = 24.5`。

---

## 反解完必须做的一件事

把结果写进 `atlas.json`，然后在**任意一张平面图上画指北针**核对：
`plot_06_building.py` 与 `plot_00_overview.py` 都按 `true_north_in_model()` 画针，
如果指北针方向与卫星图上的北方向一致，朝向才算过。

---

## 常见错误

| 症状 | 原因 |
|---|---|
| 风玫瑰与当地季风规律相反 | `brg` 多了 180° |
| 阴影图里建筑"影子朝南" | 方位角定义搞成了「吹向」而不是「来自」 |
| 所有图都对，但日照率异常低 | 单位错（模型是毫米），高度场被放大 1000 倍 |
| 指北针指向场地对角 | 把 `brg_x` 当成 `brg_y` 填了（差 90°） |
